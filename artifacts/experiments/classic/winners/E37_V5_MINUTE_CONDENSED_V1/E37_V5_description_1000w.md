E37_V5 is the leak‑safe winner built for KMIA daily Tmax trading at a 06:00 UTC decision time. The system preserves the exact E37 prediction graph that made the original model strong and then adds condensed minute‑data signals as a strict residual enhancement. The final prediction remains pred(T) = base(T) + MoE_residual(T), where base(T) is the online bias‑corrected baseline computed from MOS and recent truth, and the MoE residual corrector is gated by onshore versus offshore flow. This structure matters because the baseline already captures most of the synoptic signal, and the experts only learn smaller, regime‑specific corrections rather than trying to predict absolute Tmax from scratch.

The baseline base(T) is the bias‑corrected median ensemble built from MOS forecasts at or before the decision time. The bias correction updates online using realized Tmax through day T‑1, which is fully known by 06Z day T. This is why the model is configured for 06Z decision time: it closes the leakage risk that would exist if the bias state tried to use a truth value that had not actually occurred yet. The minute‑data features are only used as additional inputs to the residual experts or the stacked corrector, never as a replacement for the baseline. That preserves the “strong anchor plus small correction” pattern that delivered the original E37 edge.

The system uses a soft mixture‑of‑experts. A gate predicts the probability of onshore flow using wind components and day‑of‑year features. Two residual experts are trained: one specialized for onshore days and one for offshore days. Each expert receives MOS residual features plus the condensed minute‑derived features. The gate weights the two expert residuals into a single correction that is added back to the baseline. This is the precise mechanism that yields robust performance and prevents the model from overreacting to noisy signals.

The minute‑data signals are derived from 1‑minute temperature observations from IEM, but are processed in a leak‑safe way. All minutes used for “T‑1 day” features are drawn from the completed local day T‑1, which is fully known by 06Z on day T. For “early‑T” features, only minutes up to 06Z on day T are used. A translation state is computed to align IEM to the NWS settlement sensor, because the IEM series is not the settlement truth. That translation is based only on historical differences through T‑1 and never uses future observations.

The condensed minute‑feature set is intentionally small but high‑signal. It includes a T‑1 diurnal fingerprint (range, time of Tmax, plateau length, heating and cooling slopes, and convective drop statistics), and an early‑night state (00Z/03Z/06Z temperatures, night cooling drop, slope and variability in the last 3 hours). It also includes translator features (diff lag, EWMA of diff, rolling diff variability) and two summary indices: a suppression index that captures cloudy or convective regimes and a late‑surge index that captures delayed heating days. These features are designed to inform the residual experts about day‑to‑day regime persistence, which MOS sometimes misses.

The baseline reproduces ~0.81 test MAE, and V5 improves this to ~0.706 test MAE. That improvement is not achieved by changing the model skeleton; it is achieved by injecting carefully constructed minute‑data features into the residual correction layer.
