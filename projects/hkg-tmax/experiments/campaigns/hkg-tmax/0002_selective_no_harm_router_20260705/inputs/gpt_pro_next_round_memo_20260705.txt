HKG Tmax Residual-ML Next-Round Research Memo
Executive conclusion

The 2026-07-05 run was a clean, leakage-safe calibration improvement, not a trading-grade breakthrough.

The system did what it was supposed to do: it anchored on the latest eligible Info.gov local official forecast max, predicted a residual correction, passed the leakage audit with zero violations, improved MAE, improved RMSE, improved p90 error, and removed almost all average bias. But the gain was only:

Raw official MAE: 0.9308580565°C
Final residual ensemble MAE: 0.8986654294°C
Improvement: 0.0321926271°C
Decision: no_promote_cosmetic

That is below the predeclared 0.035°C meaningful-edge threshold. The run should not be promoted.

The main reason the gain was small is clear: the official forecast anchor is already strong, and the residual model mostly learned a conservative upward bias correction. It helped when the official forecast was too low, but it often harmed rows where the official forecast was already correct or too high. The next round should not be “more generic ML.” It should be a selective no-harm correction system: apply residual corrections only when the model has evidence that correcting is likely to beat leaving the official forecast untouched.

That limits the exact scoped-diff audit. It does not materially limit the numerical result audit because the required result artifacts, code files, config, logs, prediction rows, scoreboards, lineage, and audits were present.

Public-source context is consistent with the package’s source contract: HKO’s climate page exposes Daily Extract resources and states data is updated up to the previous day, supporting the rule that Daily Extract is target/settlement truth, not a same-day predictor. HKO’s local forecast page states the bulletin has regular updates around 45 minutes past each hour plus 16:15 and 23:15 HKT, which matters for cutoff/issuance analysis. The HKO OpenData flw endpoint also shows the live local forecast structure, including forecastDesc, updateTime, and urban/New Territories temperature wording, but it should remain a cross-check rather than the primary historical anchor.

2. Result diagnosis: why the gain was small
2.1 The raw official anchor was already strong

At the primary cutoff tminus1_2359, the raw official forecast scored:

n = 5,629
MAE = 0.930858°C
RMSE = 1.195757°C
median absolute error = 0.700000°C

That is already a strong public anchor. The official forecast is not a weak baseline. The residual model is trying to improve a relatively small remaining error, not solve the whole forecasting problem.

That correlation is real but weak. The model had signal, but not enough to justify aggressive all-row corrections.

2.4 The all-row correction helped 55% of rows and worsened 45%

At the primary cutoff:

rows: 5,629
helped rows: 3,100 = 55.1%
worsened rows: 2,529 = 44.9%
mean absolute-error improvement: 0.0322°C
median absolute-error improvement: 0.0301°C

That is the central diagnosis.

The model had enough edge to help slightly more rows than it harmed. But it was not discriminating enough. It corrected almost every row, including many rows where the official forecast was already correct or already too high.

This is why the next round should be selective correction.

Direct absolute prediction should remain diagnostic only.
