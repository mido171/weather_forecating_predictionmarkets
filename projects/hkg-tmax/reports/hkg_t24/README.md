# HKG T24 Reports

Generated and curated reports for the HKG T+24 / H24N full strategy implementation belong here when a Jira does not require a more specific root-level `reports/...` path.

Jira contract coverage reports should live under:

```text
reports/hkg_t24/jira_coverage/
```

If a binding contract explicitly requires a canonical report path at `reports/<name>`, produce that canonical path and optionally mirror/index it here.
