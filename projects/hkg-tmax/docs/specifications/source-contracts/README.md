# Source Contracts

Create one `<source_id>.md` per implemented source using:

```text
Purpose
Official evidence
Endpoint/query
Authentication
Terms/license
Cadence
Coverage
Response schema
Units
Station/entity mapping
Timestamp semantics
Expected latency
Revision behavior
Point-in-time role
Quality checks
Failure handling
Rate limits
Raw path
Parser version
Tests
Known limitations
```

An entry in `config/data_sources.yaml` does not become production eligible until its source contract is complete.
