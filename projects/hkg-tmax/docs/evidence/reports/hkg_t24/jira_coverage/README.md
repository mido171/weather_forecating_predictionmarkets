# Jira Contract Coverage Reports

Each implementation Jira must produce one coverage report proving that its implemented code, tests, artifacts, and leakage controls map back to the binding contract.

Expected reports:

```text
jira_001_contract_coverage.md
jira_002_contract_coverage.md
jira_003_contract_coverage.md
jira_004_contract_coverage.md
```

If a Jira packet requires the same report under a canonical root `reports/...` name, keep that canonical report and mirror or index it here.
