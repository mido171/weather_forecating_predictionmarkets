## OOF Fold Design

R0 yearly expanding folds:

```text
R0_2005: train 2000-01-02..2004-12-31, test 2005
...
R0_2023: train 2000-01-02..2022-12-31, test 2023
```

R1 half-year expanding folds:

```text
R1_A: train 2021-03-23..2021-12-31, test 2022-01-01..2022-06-30
R1_B: train 2021-03-23..2022-06-30, test 2022-07-01..2022-12-31
R1_C: train 2021-03-23..2022-12-31, test 2023-01-01..2023-06-30
R1_D: train 2021-03-23..2023-06-30, test 2023-07-01..2023-12-31
```

Minimum training rows:

```text
R0 experts: 1000
R1 experts: 250
specialists later: 200 active rows for promotion
```

OOF rule:

```text
train_end_date < prediction target_date_hkt
```

## Model Selection

Use LightGBM mandatory for gradient boosting models. Linear baselines may use Ridge, ElasticNet, Huber.

R0 inner validation:

```text
If training_rows >= 1095:
  inner_train = all outer-training rows except final 365 chronological days
  inner_validation = final 365 chronological days
Else if 730 <= training_rows < 1095:
  inner_train = first 70% chronological rows
  inner_validation = final 30%
Else:
  no inner validation, use default hyperparameters
```

R1 inner validation:

```text
If training_rows >= 365:
  inner_train = all outer-training rows except final 90 chronological days
  inner_validation = final 90
Else:
  no inner validation, use defaults
```

Tie-breaking:

```text
1. lowest inner validation MAE
2. if tied within 0.002°C, lowest P90 AE
3. if tied, lowest absolute bias
4. if tied, fewer features
5. if tied, stronger regularization
6. if tied, smaller correction cap
7. if tied, lexicographically smallest hyperparameter JSON
```
