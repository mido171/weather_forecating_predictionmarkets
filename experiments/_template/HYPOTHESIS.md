# Hypothesis

## Mechanism

Explain the causal/physical/statistical reason this information should change the forecast distribution.

## Exact prediction

Specify expected:

- sign or distributional change;
- affected regimes;
- unaffected/failure regimes;
- forecast horizons;
- magnitude range if defensible.

## Null hypothesis

State what no useful incremental information would look like.

## Falsification

List findings that would reject the hypothesis.

## Novelty and prior evidence

Cite prior experiments or external authoritative evidence. Distinguish inspiration from proof.

## Leakage risks anticipated

List likely ways this feature or target could contain future information.
