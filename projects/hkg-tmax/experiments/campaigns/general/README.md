# General experiment campaign

This campaign is reserved for falsifiable research that genuinely spans
multiple HKG Tmax domains and does not fit `hkg-tmax`, `hkg-t24`,
`residual-modeling`, `probability`, or `market-edges`.

It is never an implicit default or an engineering task log. Select it
explicitly with `--campaign general`, state why no narrower campaign owns the
hypothesis, and add governed experiments to this README only after allocation.
