# Market-edge campaign

This campaign stores weather-model-versus-market snapshots. It never places
orders, uses account credentials, or authorizes execution.

| Experiment | Snapshot |
|---|---|
| [Live market edges](live-market-edges/README.md) | HKG highest-temperature event for 2026-07-06 |

Market prices are comparison inputs only. They are not meteorological model
features. The JSON snapshot is the machine source of truth; the experiment
README is the concise human interpretation.
