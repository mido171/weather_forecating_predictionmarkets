# HKG Tmax First Goals

This file is a compatibility entry point for workflows that refer to
`HKG_TMAX_FIRST_GOALS.md`.

The canonical ordered goal program is `FIRST_GOALS.md`. It defines G0 through
G10 for the Hong Kong Observatory Tmax research system, including the immediate
G0 requirement to prove the repository and archive work end to end before any
target-parity, horizon, baseline, or modelling work begins.

For execution, read and follow `FIRST_GOALS.md`. Do not treat this file as a
separate or divergent goal list.
