# Glossary

**As-of cutoff:** Exact time beyond which information is forbidden for a forecast.

**Available at:** Earliest defensible time a record could be consumed.

**Bucket:** Mutually exclusive contract temperature interval.

**Canonical target:** Contract-authoritative first-published value after G1 verification.

**CLMMAXT:** HKO API data type for Daily Maximum Temperature.

**CRPS:** Proper scoring rule for a full continuous predictive distribution.

**Daily Extract:** HKO product named by the current Hong Kong Polymarket rules.

**First publication:** Earliest public value used under current no-later-revision wording.

**H24N:** Candidate cutoff at 15:00 HKT on T-1, nominally 24 hours before 15:00 on T.

**HKO:** Depending on context, Hong Kong Observatory organization or station code; code identity must be explicit.

**Locked test:** Untouched period reserved for final verification.

**Model vintage:** One specific forecast cycle/issue/member as actually available.

**Point in time:** Reconstructing only what was known by a historical cutoff.

**Rules hash:** Hash of exact/normalized event rules used to detect changes.

**Settlement emulator:** Code mapping authoritative decimal Tmax into the exact winning outcome.

**Shadow forecast:** Immutable live forecast made before outcome without live execution.

**T:** Hong Kong local target calendar date.

**Tmax:** Daily maximum air temperature under the authoritative product’s observation/aggregation convention.
