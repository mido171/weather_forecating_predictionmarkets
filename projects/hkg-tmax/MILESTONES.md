# Current milestone dashboard

This short dashboard contains only current, verified pointers.

- Repository consolidation: implemented on the migration branch; see
  `docs/status/CURRENT_STATE.md`.
- Historical research milestone record: `docs/archive/HISTORICAL_MILESTONES.md`.
- Active experiment inventory: `EXPERIMENT_INDEX.md`.
- Current work and release gates: `docs/status/NEXT_ACTIONS.md`.

Do not add an accuracy or production milestone unless its experiment passes the
point-in-time, locked-test, reproducibility, and independent-review gates.
